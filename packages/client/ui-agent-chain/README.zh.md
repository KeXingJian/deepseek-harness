# @deepseek-ai/dsh-client-ui-agent-chain

[English](README.md) | 中文

## 概述

评审执行链视图把单个会话的 agent 活动压缩成一条可读的执行链，放在会话视图里。<br>它注册 `执行链`（英文 `Chain`）视图标签，渲染 `dsh-agent-activity` 投影产出的八类卡片，支持筛选、展开单卡记录的事实与依据，并在右侧定位条上只引导提示词与改动卡片。<br>卡片记录的路径可在右侧栏预览中打开文件，依据行可在“轨迹”中打开对应工具调用。<br>插件只在浏览器运行；Node 侧是一个空的 `apply`，只为让这个包成为一条 Loader 行。

<a id="use-this-package"></a>
## 使用本包

把插件与 `ui-conversation`、`ui-renderer`、`ui-primitives` 一起挂载；它声明依赖 `slots`、`uiConversation`、`locale`。<br>会话一旦有可折叠的活动，标签就会出现在“对话”和“轨迹”旁边。

### 阅读执行链

每行包含状态点、带字形与类型名的类别标签、一行标题；投影合并了重复工作时还会带上重复次数。<br>卡片类型有 `prompt`、`thinking`、`intent`、`recon`、`change`、`verify`、`interrupt`、`result`。<br>配色按作用域而非单个类型分配：每行的左侧色条、底色与类别标签墨色都取自同一个作用域色——人的提示词用蓝色，推理（`thinking`、`intent`）用紫色，勘察压到中性灰，需要评审者阅读或回应的改动与人工交接（`change`、`interrupt`）用琥珀色，验证用绿色，收尾结论用正文墨色。<br>失败会盖过作用域色改用错误色；状态点与标题颜色仍然表示健康状态。<br>思考卡片比意图卡片更安静：色条是虚线，标签不带底色。<br>思考卡片还多一行该步骤的行动计数摘要，按读者语言组合，并拥有该步骤的行动子卡：子卡缩进挂在它下面，各自带展开按钮，一行读完"想了什么、做了什么"而不用离开这个步骤。<br>投影把每个标题作为消息描述符提供，失败卡片始终单独成卡；措辞由本包字典拥有，并由 `chain-copy.ts` 解析。

执行链默认按事件时间排列，每个事件单独显示。<br>`显示合并事件`切换到合并视图：相邻勘察卡、同一文件的重复修改、连续成功验证和近似重复意图会折叠；合并卡按其首个依据事件的序号排序，重复修改只在两条提示词之间的那一段内保留首次出现的位置，因此定位条上两条相邻请求之间仍然看得到改动；结论卡在两种模式下都位于末尾。<br>两个控制都放在左侧：合并切换与`隐藏勘察`。

`隐藏勘察`会移除勘察卡片，包括思考卡片下的勘察子卡，但保留该思考卡的其他子卡。<br>按钮文字说明下一步会做什么（`隐藏勘察` / `显示勘察`），按下态不是唯一信号。

### 阅读长链

任意长度的执行链都按页渲染。<br>第一页是前 40 张顶层卡片，读者滚到末尾时列表再追加一页：卡片下方的哨兵进入滚动容器即自动追加，同一个控件同时是可点击的按钮，因此没有 `IntersectionObserver` 的浏览器和键盘读者可以手动翻页。<br>切换任一导航控制会回到第一页，读者不会落在另一份列表的中段。

卡片列右侧的定位条只引导评审者真正要读的卡片：每张提示词卡片和每张改动卡片一根横杠，颜色取自该卡片的作用域色。<br>悬停或键盘聚焦横杠时，会显示卡片标题与已记录的改动说明。<br>思考卡片只有在折叠出改动时才占一根横杠，因此定位条不会指向什么都没改的推理。<br>横杠是转录里轮次导航横杠的两倍大；定位条把自身挂在读者真正看得见的那条带的中线上——带高取滚动容器高度减去贴底的输入区，两者都由会话外壳发布——卡片滚动时停在中线，滚到列表末尾、以及追加一页把列表撑长时也一样：横杠列挂在一个零高的粘性锚点上，而不是自己粘着，因此不会停在包含块的底边；被引导的卡片比该带更高时在自身范围内滚动。<br>一个覆盖这些行的 `IntersectionObserver` 按卡片列表顺序标出上部阅读带里最靠前的被引导卡片，横杠因此随滚动跟随读者；点击横杠会把该卡片滚到滚动容器上沿——卡片落在当前页之外时，先把执行链渲染到它为止。<br>可引导的卡片少于两张时不显示定位条，卡片独占整行。<br>视图宽度低于 560px 时放弃定位条以保证卡片宽度，卡片仍可通过滚动访问。

### 展开单张卡片

记录了本回合意图的改动卡片会在标题与差异之前醒目显示该意图。<br>执行链文字使用 1.5 倍字号。<br>打开视图时默认隐藏勘察卡片，可在工具栏显示。<br>展开按钮揭示卡片记录的内容：具名事实（用户提示词原文、步骤的思考、路径、变更说明、命令、工具、操作、文件数、检索数），以及每条来源 span 的一行——会话日志序号、span 名称与结算状态。<br>变更说明自带字段名，读者能区分点名了本文件的那句话（`本次改动原因`）、本步骤的计划（`本步上下文`）与本回合的目标（`本回合意图`）。<br>工具记录了变更原文的改动卡片，会在这些之前显示行级差异——该文件的变更前后行，按行数上限折叠并带自己的展开控件——评审员读到的就是这次编辑本身。<br>没有事实、差异或依据的卡片不提供展开按钮；快照里已不存在的依据序号会被跳过。

### 打开卡片指向的对象

路径按会话工作区根显示为相对路径，记录时的路径留在悬停标题里。<br>路径事实与风险标记里的文件都是按钮：点击在右侧栏预览中打开该文件，地址按同一个根解析，评审者可以在执行链旁直接读文件。<br>来自工具调用的依据行会通过会话的检查目标在“轨迹”中打开该调用；轮次与步骤 span 保留序号，但没有可检查的调用。

<a id="understand-the-implementation"></a>
## 理解实现

插件在 `apply` 里贡献四样东西：`agentChain` 字典、一个 Conversation Definition、一个 Conversation 视图 target，以及一个 `conversation.view` 槽位条目。

- `chainDefinition` 匹配执行链读取的八种持久事件，并通过 `@deepseek-ai/dsh-agent-activity` 折叠它们。<br>它同时把每条 `tool/result` 的 `diffs` 负载按调用标识记录下来——span 只保留调用标识、不保留文件文本——构建节点时再把这份记录作为 `chainFromSpans` 的第三项传入。<br>额外不落任何东西：文本本来就在日志已有的工具结果里。<br>每个匹配事件都作为 start 候选：引擎用已加载历史窗口里最早的事件初始化 Context，其余按 update 应用，窗口滑动时也会重新推导执行链。<br>它构建的节点同时携带折叠结果与来源 span，因此展开时可以按序号读取单条 span。
- `chainViewDefinition` 按会话发布一份快照 —— `{ cards, flags, spans }` —— 来自 Definition 构建的节点。<br>该节点复用引擎生成的 Context key；自己手写的 key 过不了引擎的身份校验。
- `AgentChainView` 通过槽位的 `useChain` hook 与 `t` 座位渲染快照。<br>它通过框架的 `useSessions` 座位读取会话工作区根，把每个要显示的路径相对它缩短，而 `openFile` 仍然收到记录时的路径。<br>`chain-copy.ts` 持有筛选与类型字形的词汇，通过字典解析卡片标题，推导展开行与依据行，并在读者隐藏勘察时移除勘察卡片，因此组件里既没有文案副本，也不访问服务。<br>`locator.ts` 把提示词与改动卡片映射为定位条横杠、观察这些行并滚动到选定卡片；`stream.ts` 持有每页渲染数量与追加哨兵。<br>视图从会话视图的 owner share 收到 `inspectCall`，并用 span 记录的调用标识调用它。
- 槽位的 `inject` 面在点击时从 `sessions.list` 读取会话工作区根，把卡片路径解析为会话作用域的文件地址并通过 `sidebarRight.openResource` 打开；读取文件内容由预览自己负责。
- 样式是一个基于 `--dsw-*` 令牌的 CSS Module；根节点宽度限制在 `--dsh-chat-content-width`，并声明 inline-size 容器查询，让列表与定位条的断点跟随视图列宽而不是窗口宽度；自身不滚动，滚动由会话滚动容器负责。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与延期工作

- **未选中的对话视图会卸载** —— 切换到其他视图会丢失执行链组件的本地筛选、展开状态和滚动位置；保留未激活视图需要修改共享 `ui-conversation` 渲染器。
- **计数没有单复数形式** —— 字典消息接收数字后只渲染一个模板，因此英文执行链会显示 "1 searches" 而不是单数形式。
- **执行链自身还不能折叠** —— 命中的卡片都会渲染，只是一次渲染一页；尚无“全部收起”或按类型分组。
- **风险标记只以卡片状态到达读者** —— 投影仍会计算它们并标记受影响的卡片，但视图不再列出任何标记，读者看不到标记自身的原因和证据文件。
- **轮次与步骤依据不能跳转** —— 只有工具调用 span 带有“轨迹”可聚焦的调用标识，因此轮次与步骤依据行只是标签。
- **新建文件缺少已记录的全文差异** —— 创建工具当前不提供旧文本或已应用的新增文本，卡片只显示路径与操作；视图不会去读文件倒推。
- **差异只覆盖记录下来的文本** —— 工具结果里没有 `diffs` 的改动（shell 删除、只上报操作类型的工具）只显示路径与操作，不显示差异；视图不会去读文件倒推。
- **子卡属于它所在的步骤** —— 同一文件在两个步骤里各改一次，就是两张卡片、分属两张思考卡，因为卡片属于促成它的那段思考。

<a id="dev-note"></a>
### 开发备注

标签注册进 `conversation.view`，而不是右侧栏：执行链是对单个会话的一种阅读，而视图标签栏已经承载了该会话的其他阅读方式（对话、轨迹）。<br>文件链接随后落在右侧栏，因为它的预览已经能解析会话作用域的文件地址；执行链本身从不读取文件。
